# Wattiz

Projeto React/Vite da plataforma Wattiz.

## Estrutura principal

- `src/main.tsx`: entrada do app e navegação interna.
- `src/components/wattiz/`: componentes reais do site, login, cadastro e dashboard.
- `src/assets/logos/`: logos da Wattiz.
- `src/assets/videos/`: vídeos usados na landing page.
- `src/assets/images/landing/`: imagens da página inicial.
- `src/assets/images/lume/`: imagens da Lume IA.
- `src/assets/images/produtos/`: imagens usadas nos produtos/hardware/loja.
- `src/assets/images/auth/`: imagem da tela de login/cadastro.
- `src/assets/images/dashboard/`: imagens do dashboard/perfil.
- `src/styles.css`: estilos globais do site.

## Comandos

```bash
npm install
npm run dev
npm run build
```
